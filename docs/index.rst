sciro API reference
===================

The ``sciro`` package extends the `Pybricks API <https://docs.pybricks.com>`_
on the PeakHub. It is frozen into the PeakHub firmware; the same modules are
published as typed stubs in the ``scirodev`` package for your IDE.
